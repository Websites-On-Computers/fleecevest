# Examples

Three product artifacts, the same product need shown before and after the
vest.

- `prd-dark-mode.md` — vision doc vs. one-page PRD.
- `tickets-breakdown.md` — flat task list vs. outcome-named epics and tickets.
- `review-teardown.md` — vague PRD excerpt vs. a fleecevest-review teardown.

The Before halves are deliberately bad — buzzwords, no baselines, no kill
criteria — so the After halves have something real to cut. Don't write like
the Before halves.

Try it on your own doc: run `/fleecevest-prd` (or `/fleecevest-tickets`,
`/fleecevest-review`) against it.
